# assembly-mips-lista-3
Exercícios de Assembly MIPS desenvolvidos na disciplina de Arquitetura e Organização de Computadores da FATEC Zona Leste.
Exercícios

Volume de um paralelepípedo: cálculo do volume a partir das dimensões informadas.

Comprimento de uma circunferência: cálculo utilizando o valor de PI igual a 3.

Diferença entre números: identificação do maior e do menor entre dois números e cálculo da diferença entre eles.

Média de notas: cálculo da média de quatro notas e classificação do aluno como aprovado, em exame ou retido.

Soma de números ímpares: cálculo da soma dos números ímpares existentes entre dois valores informados.

Maior e menor valor: identificação do maior e do menor entre dez números positivos, solicitando novamente valores inválidos.

Tecnologias utilizadas

Assembly MIPS

Simulador MARS
